# 02 不能用 Image2 生成，必须用前端代码实现的内容

## 一、页面结构

必须用代码实现：

- Sidebar；
- Topbar；
- Content layout；
- Grid layout；
- Card layout；
- Drawer；
- Modal；
- Tabs；
- Pagination。

## 二、业务数据

必须用代码实现：

- 价格数据；
- 设备清单；
- 地材清单；
- 供应商列表；
- 询价任务；
- 比价表；
- BOQ解析结果；
- AI任务流；
- 风险清单；
- 审核记录。

## 三、表格和表单

必须用代码实现：

- 数据表格；
- 筛选器；
- 输入框；
- 下拉框；
- 日期选择；
- 上传组件；
- 批量操作；
- 编辑表单；
- 新增弹窗。

## 四、图表

必须用代码或 SVG 实现：

- 折线图；
- 环形图；
- 雷达图；
- 柱状图；
- 趋势 sparkline；
- 进度条；
- 置信度条；
- 地区分布图。

推荐使用：

```text
Recharts
ECharts
SVG component
CSS progress bar
```

## 五、文字和数字

所有文字和数字必须是 HTML 文本，不得嵌入图片：

- 页面标题；
- 表格字段；
- 价格；
- 日期；
- 供应商名称；
- 状态；
- AI建议；
- 风险提示；
- 报告内容。

## 六、原因

这些内容需要：

- 可搜索；
- 可更新；
- 可筛选；
- 可复制；
- 可导出；
- 可响应式；
- 可接数据库；
- 可被AI读取和处理。

所以不能用 Image2。
