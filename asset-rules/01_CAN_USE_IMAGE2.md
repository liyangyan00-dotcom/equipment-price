- 数据网格；

- 背景氛围图。


## 七、Image2 生成要求

所有 Image2 图片必须：

1. 不包含关键文字；
2. 不包含具体价格数字；
3. 不替代表格或图表；
4. 不作为按钮、菜单、筛选器；
5. 尺寸和用途明确；
6. 压缩后放入 assets 对应目录。
