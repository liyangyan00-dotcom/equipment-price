# 00 资产使用决策树：Image2 / SVG / 前端代码

## 一、先判断：这个元素是否承载业务数据？

### 是

必须用前端代码实现。

包括：

- 表格；
- 价格数据；
- 统计卡；
- 筛选项；
- 图表；
- 状态标签；
- 进度条；
- 按钮；
- 弹窗；
- 表单；
- 菜单；
- 文字内容。

### 否

可以继续判断是否适合图片或 SVG。

## 二、是否是简单线性图标？

### 是

优先用 SVG / lucide-react / icon component。

包括：

- 菜单图标；
- 功能入口图标；
- 状态小图标；
- 上传、下载、编辑、删除、查看、筛选；
- AI、报价、供应商、附件、统计等功能图标。

### 否

继续判断是否是氛围图、背景图、插图。

## 三、是否是复杂视觉氛围图？

### 是

可以用 Image2 生成。

包括：

- 登录页水厂背景；
- 侧边栏底部水厂照片化背景；
- 空状态插图；
- AI智能助手插图；
- 报告封面背景；
- 水厂工程概念图；
- 数据网络抽象背景。

### 否

用 CSS / SVG / 前端组件实现。

## 四、总原则

| 类型 | 推荐方式 |
|---|---|
| 页面布局 | 前端代码 |
| 表格 | 前端代码 |
| 图表 | Recharts / SVG代码 |
| 按钮 | 前端代码 |
| 状态标签 | 前端代码 |
| 线性图标 | SVG / lucide-react |
| 品牌Logo | SVG |
| 水厂背景图 | Image2 |
| 空状态插图 | Image2 或 SVG |
| AI助手装饰 | Image2 或 SVG |
| 报告封面图 | Image2 |
| 页面整图 | 只能作为参考图，不能用于前端页面 |
