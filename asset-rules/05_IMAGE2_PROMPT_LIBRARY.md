# 05 Image2 生图提示词库

## 1. 登录页背景

```text
生成一张16:9宽屏网页背景图，主题为水厂项目机电设备与地材价格信息库，深蓝科技风，包含现代水厂沉淀池、滤池、管道、数据网格、AI数据流元素，画面干净专业，适合作为网页登录页背景。不要出现文字、不要出现具体价格数字、不要出现按钮和表格。
```

## 2. 侧边栏水厂底图

```text
生成一张竖向网页侧边栏底部装饰图，深蓝色调，现代水厂圆形沉淀池俯视角，轻微数据网格和工程线条，适合放在后台系统左侧导航底部。不要文字，不要按钮，不要表格。
```

## 3. 空状态插图

```text
生成一张简洁的后台系统空状态插图，主题为暂无数据，包含文件夹、数据表、放大镜、AI小图标，蓝白配色，轻量扁平风格，适合水厂工程价格系统。不要文字。
```

## 4. AI报价识别插图

```text
生成一张AI报价识别功能插图，画面包含PDF报价单、Excel表格、AI扫描光线、结构化数据卡片，蓝紫科技风，适合后台系统卡片装饰。不要文字，不要具体数字。
```

## 5. AI报告生成封面背景

```text
生成一张工程商务报告封面背景图，主题为水厂项目价格分析报告，包含现代水厂、数据图表、蓝色科技网格、AI智能分析元素，专业、干净、适合报告封面。不要文字。
```

## 6. AI价格采集插图

```text
生成一张AI价格采集功能插图，包含搜索雷达、供应商节点、设备价格标签、地材市场线索、数据网络，蓝紫科技风，适合后台系统AI价格采集中心。不要文字。
```
