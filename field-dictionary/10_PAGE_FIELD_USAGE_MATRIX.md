# 10 页面字段使用矩阵

| 页面 | 主要数据对象 | 必须显示字段 |
|---|---|---|
| 首页 | dashboardSummary | 价格条目、供应商数、待审核、AI任务、高风险、趋势 |
| 机电设备价格库 | equipmentPrices | 设备编号、名称、类别、规格、供应商、价格、币种、美元价、可信度、状态、日期 |
| 设备价格详情 | equipmentPrice | 基本信息、技术参数、报价信息、供应商、附件、历史版本、审核记录 |
| 地材价格库 | materialPrices | 材料编号、名称、类别、规格、地区、单位、价格、运输、可信度、状态 |
| 供应商库 | suppliers | 编号、名称、国家、类型、主营产品、联系人、响应速度、价格水平、技术能力、风险、评分 |
| 供应商详情 | supplier | 基本信息、联系人、历史报价、评分、合作记录、风险 |
| AI报价识别中心 | pendingQuote/aiTask | 文件、供应商、日期、币种、条目、置信度、缺失、风险 |
| 待审核报价池 | pendingQuotes | 文件名、类型、供应商、日期、币种、AI置信度、缺失、风险、状态 |
| AI价格采集中心 | priceLeads/aiTasks | 线索编号、名称、规格、来源、价格、币种、地区、匹配度、可信度 |
| 价格线索池 | priceLeads | 线索类型、名称、规格、来源、价格、状态、风险、操作 |
| 询价与比价管理 | inquiryTasks | 询价编号、任务名、项目、设备数量、供应商数、回收数、截止日期、状态 |
| 比价表详情 | comparisonTable | 设备、规格、数量、供应商报价、最低价、推荐价、技术偏差、风险 |
| 项目套价中心 | projectPricing | BOQ项数、匹配等级、匹配价格、供应商、可信度、成本汇总 |
| 附件证据库 | attachments | 文件名、类型、关联对象、供应商、来源、上传人、时间、状态 |
| 统计分析 | analytics | 价格趋势、分类占比、供应商分布、可信度、风险类别 |
| AI工作台 | aiTasks | 任务编号、类型、来源、状态、置信度、风险、负责人 |
| AI报告中心 | reports | 报告名称、类型、项目、生成方式、状态、时间、导出 |
| 系统设置 | settings | 汇率、分类、可信度规则、审核流程、AI参数、用户角色 |
