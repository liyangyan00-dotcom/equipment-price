# 12 28页视觉模式总结

## 01 首页 / AI增强价格雷达

视觉模式：

```text
统计卡 + AI洞察卡 + 趋势图 + 待处理任务 + 风险预警
```

重点：

- 大数字指标；
- 蓝紫 AI 模块；
- 风险提示区；
- 多卡片仪表盘布局。

## 02 机电设备价格库

视觉模式：

```text
PageHeader + 筛选区 + 高密度表格 + 状态标签 + AI推荐入口
```

重点：

- 表格行高统一；
- 可信度标签明显；
- 金额右对齐；
- 操作列简洁。

## 03 设备价格详情

```text

```

重点：

- 信息分组清晰；
- 价格和风险突出；
- 附件证据链入口明显。

- 风险提示。
