# 06 按钮、表单、筛选器规范

## 一、按钮类型

| 类型 | 样式 | 用途 |
|---|---|---|
| Primary | 工程蓝背景 + 白字 | 新增、确认、保存 |
| Secondary | 白底 + 蓝色边框 | 次要操作 |
| Ghost | 透明背景 + 灰蓝文字 | 表格行操作 |
| AI | 蓝紫渐变 + AI图标 | AI识别、AI生成、AI分析 |
| Warning | 橙色描边/浅背景 | 需补充、预警 |
| Danger | 红色描边/红字 | 作废、退回、删除 |

## 二、尺寸

| 类型 | 高度 | 圆角 | 字号 |
|---|---:|---:|---:|
| 大按钮 | 40px | 10px | 14px |
| 标准按钮 | 36px | 10px | 14px |
| 小按钮 | 30px | 8px | 12px |
| 表格操作按钮 | 28px | 8px | 12px |

## 三、AI按钮

```css
background: linear-gradient(135deg, #0B5CAD 0%, #7C3AED 100%);
color: #FFFFFF;
box-shadow: 0 8px 24px rgba(124,58,237,0.18);
```

用于：

- AI报价识别；
- AI价格采集；
- AI比价分析；
- AI套价；
- AI报告生成。

## 四、表单控件

| 元素 | 规范 |
|---|---|
| Input | 36/40px 高，圆角 10px |
| Select | 与 Input 同高 |
| DatePicker | 与 Input 同高 |
| Textarea | 圆角 12px |
| Checkbox | 使用统一蓝色选中 |
| Upload | 虚线边框 + 图标 + 说明 |

## 五、筛选器

筛选区视觉：

```text
白色卡片或浅色工具条
高度 48px - 64px
控件间距 8px - 12px
搜索框放左侧
高级筛选放右侧
主操作按钮放最右
```

## 六、禁止事项

1. 不要使用浏览器默认按钮；
2. 不要所有按钮都用主色；
3. 不要 AI按钮和普通按钮混淆；
4. 不要危险操作没有红色提示；
5. 不要筛选区高度不统一。
