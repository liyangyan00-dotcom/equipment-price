# 11 空状态视觉规范

## 一、适用场景

- 暂无设备价格；
- 暂无地材价格；
- 暂无供应商；
- 暂无待审核报价；
- 暂无附件证据；
- 暂无搜索结果；
- 暂无AI任务。

## 二、空状态结构

```text
插图
标题
说明文字
主操作按钮
次操作按钮（可选）
```

## 四、视觉尺寸

```text
插图宽度：160px - 220px
标题：16px / 600 / #1E293B
说明：13px / #64748B
按钮：36px 高
内容居中
上下留白：32px - 48px
```

## 五、文案建议

| 场景 | 标题 | 操作 |
|---|---|---|
| 设备价格 | 暂无设备价格数据 | 新增设备价格 / 上传报价 |
| 地材价格 | 暂无地材价格数据 | 新增地材价格 / AI采集 |
| 供应商 | 暂无供应商数据 | 新增供应商 |
| 待审核报价 | 暂无待审核报价 | 上传报价文件 |
| 附件证据 | 暂无附件证据 | 上传附件 |

## 六、禁止事项

1. 不要空白无提示；
2. 不要只显示“暂无数据”四个字；
3. 不要插图过大；
4. 不要用同一张插图覆盖所有场景；
5. 不要把空状态插图用于有数据页面的主体区。
