# 08 图表视觉规范

## 一、通用规则

所有图表必须用代码实现，推荐：

```text
Recharts
ECharts
```

不得使用：

- Image2 生成图表；
- UI参考图截图；
- 静态图片图表。

## 二、图表容器

图表必须放在 `ChartCard` 中：

```text
白色背景
16px 圆角
浅边框
轻阴影
顶部标题 + 右侧筛选/图例
```

## 三、折线图

| 项 | 规范 |
|---|---|
| 主线 | 工程蓝 `#0B5CAD` |
| 辅助线 | 青蓝 `#00A6B8` / AI紫 |
| 线宽 | 2px - 3px |
| 点 | 小圆点，hover放大 |
| 网格线 | `#E2E8F0` |
| Tooltip | 白底、圆角、阴影 |

## 四、柱状图

| 项 | 规范 |
|---|---|
| 主色 | 工程蓝 |
| 辅助色 | AI紫、青蓝 |
| 圆角 | 顶部 4px - 6px |
| 间距 | 不要过密 |
| Hover | 轻微加深 |

## 五、饼图 / 环形图

推荐色序：

```text
#0B5CAD
#00A6B8
#7C3AED
#F59E0B
#16A34A
#DC2626
```

环形图中心可显示总数或百分比。

## 六、雷达图

适用于：

- 供应商评分；
- 技术能力；
- 交付风险；
- 价格水平；
- AI可信度。

样式：

```text
线条：AI紫 / 工程蓝
填充：rgba(124,58,237,0.14)
网格：#E2E8F0
```

## 七、图表文字

```text
坐标轴：12px / #64748B
图例：12px / #475569
Tooltip标题：13px / 600
Tooltip值：13px / 500
```

## 八、禁止事项

1. 不要使用截图图表；
2. 不要使用默认强烈彩虹色；
3. 不要图表无标题；
4. 不要图表无单位；
5. 不要 tooltip 使用默认丑样式。
