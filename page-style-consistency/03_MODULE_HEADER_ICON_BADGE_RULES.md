# 03 模块标题、图标与 Badge 全局规则

所有页面模块标题建议使用：

```text
左侧：IconBox + 标题 + 副标题
右侧：操作 / 筛选 / 状态标签
```

IconBox：
| 类型 | 背景 | 图标色 |
|---|---|---|
| 普通数据 | 浅蓝 | 工程蓝 |
| 供应商/区域 | 浅青 | 青蓝 |
| AI | 浅紫 | AI紫 |
| 风险 | 浅橙/浅红 | 橙/红 |
| 成功 | 浅绿 | 绿色 |
| 文档/附件 | 浅灰蓝 | 蓝灰 |

图标策略：
1. 第一优先：lucide-react；
2. 第二优先：项目 SVG；
3. 禁止为普通图标生成 PNG；
4. 禁止多套图标混用。

全局 Badge：
1. AiBadge；
2. RiskBadge；
3. ConfidenceBadge；
4. StatusBadge；
5. SourceBadge；
6. CurrencyBadge。
