# 00 从首页继承的全局风格原则

核心原则：

```text
继承首页视觉语言，不照搬首页布局。
```

所有页面必须继承：
1. 工程蓝 + AI紫 + 风险橙红；
2. 浅灰蓝页面背景；
3. 白色圆角卡片；
4. 轻边框与轻阴影；
5. lucide-react 图标优先；
6. 统一 IconBox；
7. 统一模块标题区；
8. compact 表格密度；
9. AI模块紫色识别；
10. 风险模块橙红识别；
11. 截图对比还原机制。

所有页面不得照搬：
1. 首页 6 KPI 结构；
2. 首页 Row 1 - Row 8 的驾驶舱布局；
3. 首页趋势图 + AI工作台结构；
4. 首页三联卡固定结构；
5. 首页全部模块顺序。
