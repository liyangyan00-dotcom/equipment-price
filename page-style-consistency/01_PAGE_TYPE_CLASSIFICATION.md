# 01 页面类型分类

| 类型 | 页面特征 | 适用页面 |
|---|---|---|
| Dashboard驾驶舱型 | 多指标、多图表、多任务流 | 首页、统计分析、AI工作台 |
| Table数据管理型 | 筛选、表格、批量操作 | 设备价格库、地材价格库、供应商库、待审核报价池、线索池 |
| Detail详情证据型 | 摘要、分组、证据、历史 | 设备详情、供应商详情、比价详情、报告详情 |
| AI工作流型 | 上传/输入、AI处理、结构化结果、人工复核 | AI报价识别、AI采集、BOQ解析、AI询价函、AI报告 |
| Report报告型 | 报告预览、目录、导出、版本 | 报告中心、报告预览 |
| Settings配置型 | 表单、开关、规则、权限 | 系统设置、AI设置 |

所有页面继承：颜色、字体、图标、卡片、表格、按钮、标签、AI/风险视觉。

各页面类型自定义：布局结构、模块顺序、内容密度、操作流。
