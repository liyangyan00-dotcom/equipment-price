# 05 Detail 详情证据型页面规范

适用页面：
```text
/equipment-prices/[id]
/suppliers/[id]
/comparisons/[id]
/reports/[id]
```

页面结构：
```text
DetailHeader
SummaryCards
MainInfoGroups
EvidenceAttachments
HistoryTimeline
RiskAndAiSuggestions
ActionBar
```

详情页不要过度高密度，不能为了密度牺牲可读性。

建议：
1. 关键信息摘要高密度；
2. 详细字段分组展示；
3. 附件证据清楚；
4. 历史记录有时间线；
5. 风险和 AI建议形成闭环。
