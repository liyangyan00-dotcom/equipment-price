# svg-icons 目录说明

本目录用于存放系统自定义 SVG 图标资产。

## 使用原则

1. 优先使用 lucide-react 图标库。
2. 当 lucide-react 无法满足项目识别度时，使用本目录自定义 SVG。
3. SVG 主要用于：
   - 系统 Logo；
   - 导航图标；
   - 操作图标；
   - 状态图标；
   - AI 专属图标。
4. 禁止使用 Image2 生成这些简单功能图标。
5. SVG 应保持线性、简洁、工程蓝风格。
