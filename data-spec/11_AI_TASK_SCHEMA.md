# 11 AI 任务表字段

| 字段 | 说明 |
|---|---|
| id | 主键 |
| taskCode | AI任务编号 |
| taskType | 任务类型 |
| sourceType | 来源类型 |
| sourceId | 来源对象ID |
| inputPayload | 输入内容 |
| outputPayload | AI输出 |
| confidence | 置信度 |
| riskLevel | 风险等级 |
| missingFields | 缺失字段 |
| suggestedActions | 建议动作 |
| status | 任务状态 |
| assignedReviewer | 指定复核人 |
| reviewedBy | 实际复核人 |
| reviewedAt | 复核时间 |
| reviewNotes | 复核意见 |
| createdAt | 创建时间 |
| updatedAt | 更新时间 |
