# 00 UI 100%还原总原则

## 一、目标

本项目已有 28 页 UI 参考图。前端开发目标不是“重新设计”，而是尽可能按参考图还原：

> 布局结构、颜色、间距、卡片、表格、图表、按钮、状态标签、AI模块视觉语言尽可能一致。

## 二、还原优先级

| 优先级 | 内容 | 要求 |
|---|---|---|
| P0 | 页面结构 | 必须一致 |
| P0 | 左侧导航与顶部栏 | 必须一致 |
| P0 | 主色、背景色、卡片色 | 必须一致 |
| P0 | 表格字段与状态标签 | 必须一致 |
| P0 | 统计卡与AI卡片布局 | 必须一致 |
| P1 | 图标风格 | 高度一致 |
| P1 | 图表样式 | 高度一致 |
| P1 | 按钮、筛选器、弹窗 | 高度一致 |
| P2 | 小装饰、局部插图 | 可近似一致 |

## 三、核心边界

参考图用于视觉对照，不能整页切图。

必须用前端代码实现：

- 页面布局；
- 左侧导航；
- 顶部栏；
- 卡片；
- 表格；
- 筛选器；
- 按钮；
- 标签；
- 弹窗；
- 图表；
- 文字；
- 数据状态；
- 交互逻辑。

可以用图片/生图资产实现：

- 登录页背景；
- 侧边栏底部水厂背景；
- 空状态插图；
- AI智能助手装饰图；
- 水厂示意图；
- 报告封面背景；
- 少量品牌氛围图。

## 四、还原流程

1. 打开 `visual-references/ui-images/` 中对应页面图；
2. 读取 `ui-prototype/` 对应页面规范；
3. 读取 `asset-rules/` 判断哪些用代码、哪些用 SVG、哪些用 Image2；
4. 使用组件库实现基础结构；
5. 按视觉图调整 spacing、radius、shadow、font、colors；
6. 用 `visual-references/component-redline/` 的尺寸规则复核；
7. 截图对比，逐项修正。
