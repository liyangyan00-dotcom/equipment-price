# 01 布局还原规则

## 一、画布尺寸

参考图以 16:9 宽屏为基准。

建议开发基准：

```text
1920 × 1080
```

前端应支持响应式，但第一优先级是桌面端大屏还原。

## 二、全局布局

| 区域 | 建议尺寸 |
|---|---|
| 左侧导航栏 | 250-270px |
| 顶部工具栏 | 56-64px |
| 主内容区左边距 | 与侧边栏对齐 |
| 页面内容 padding | 24px |
| 卡片间距 | 16px / 20px / 24px |
| 卡片圆角 | 12px / 16px |
| 表格行高 | 44-52px |

## 三、固定结构

所有主页面保持：

```text
Sidebar + Topbar + Content
```

Content 内部保持：

```text
页面标题区
顶部统计卡片区
筛选/操作区
主表格/主业务区
右侧AI洞察/风险区
底部图表/快捷操作区
```

## 四、禁止

- 禁止每个页面重新设计不同导航；
- 禁止替换主色；
- 禁止卡片圆角、表格风格大幅变化；
- 禁止把参考图整张作为背景；
- 禁止用图片代替动态数据表格。
