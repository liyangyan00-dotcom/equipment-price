# UI 页面参考图目录

本目录已将生成的 28 页 UI 页面统一命名并归档，供 Codex / 前端开发 / UI复核使用。

## 使用原则

1. 这些图片是视觉参考，不允许整页切图。
2. 页面结构、卡片、表格、图表、按钮、状态标签必须由前端代码实现。
3. Codex 开发页面时，应同时阅读：
   - `ui-prototype/` 对应页面说明；
   - `visual-references/` 视觉规范；
   - 本目录对应页面参考图。
4. 首页 `01_dashboard_ai_price_intelligence.png` 是全系统视觉基准。
5. 其他页面必须保持同一套风格：深蓝侧栏、顶部工具栏、浅灰白内容区、白色圆角卡片、工程蓝/青蓝主色、AI紫色辅助、橙红风险色。
