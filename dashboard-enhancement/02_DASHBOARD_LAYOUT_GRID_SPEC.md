# 02 Dashboard 布局栅格规范

## 推荐结构

```text
PageHeader
顶部 6 张压缩统计卡
AI工作台总览 + 价格趋势图
最新价格动态 + 待复核任务
AI价格情报洞察三联卡
分布图模块组
风险预警列表
底部横向快捷操作栏
```

## 12 栅格建议

顶部统计卡：

```text
grid-cols-6
```

主体第一行：

```text
左侧 8列：价格趋势图
右侧 4列：AI工作台总览
```

主体第二行：

```text
左侧 7列：最新价格动态
右侧 5列：待复核任务
```

洞察区：

```text
3张 AI洞察卡横向排列
```

分布图区：

```text
3个小图表横向排列
```

风险区：

```text
风险预警列表占满 12列
```

底部：

```text
6个快捷入口横向操作栏
```

## 信息密度要求

1. 首屏至少看到统计卡 + 2 个核心模块；
2. 卡片间距 12px - 16px；
3. 图表高度 220px - 300px；
4. 列表行高 44px - 56px；
5. 避免大面积空白；
6. 避免大插图占据业务区。
