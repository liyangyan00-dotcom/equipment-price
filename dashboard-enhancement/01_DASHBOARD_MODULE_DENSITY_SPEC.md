# 01 Dashboard 模块密度补强规范

## 一、顶部统计卡

保留 6 张统计卡，但压缩高度到：

```text
96px - 112px
```

推荐指标：

| 指标 | 说明 |
|---|---|
| 设备价格数 | 已入库设备价格 |
| 地材价格数 | 已入库地材价格 |
| 供应商数量 | 已维护供应商 |
| AI待复核 | AI识别后待人工确认 |
| 今日价格线索 | AI采集或人工新增线索 |
| 高风险价格 | 过期、异常、参数缺失 |

## 二、AI 工作台总览

字段：

```text
今日 AI 任务数
报价识别成功率
风险结果数量
AI 建议动作数量
最近一条 AI 建议
人工待复核数量
```

视觉：

```text
AI紫 + 工程蓝
AiBadge
置信度/成功率进度条
紧凑信息块
```

## 三、最新价格动态

字段：

```text
类型
名称
更新时间
价格
币种
来源
AI来源标签
可信度等级
```

示例：

```text
反冲洗水泵 / 设备 / USD 12,800 / AI报价识别 / A
电动蝶阀 / 设备 / USD 3,450 / 供应商邮件 / B
水泥 / 地材 / CDF 28,000/袋 / 市场采集 / C
钢筋 / 地材 / USD 860/t / AI价格采集 / B
Kinshasa本地运输 / 服务 / USD 320/车 / 供应商报价 / C
```

## 四、待复核任务

字段：

```text
文件类型
文件名
任务类型
AI置信度
参数缺失数量
风险等级
创建时间
查看 / 复核 / 补充资料
```

## 五、AI价格情报洞察三联卡

三张卡：

```text
线索发现
价格缺口
建议询价任务
```

每张卡必须包含：

```text
指标
说明
建议动作
AI标签或AI紫色点缀
```

## 六、趋势图和分布图

趋势图展示：

```text
设备价格趋势
地材价格趋势
AI采集线索趋势
```

分布图至少 2 个，推荐 3 个：

```text
设备分类分布
供应商区域分布
价格可信度分布
```

必须用 Recharts 或代码实现。

## 七、风险预警列表

风险类型：

```text
过期价格
低价异常
参数缺失
供应商响应慢
价格波动过大
可优先联系供应商
```

字段：

```text
风险标题
风险类型
影响对象
风险等级
建议动作
操作入口
```

## 八、横向快捷操作栏

操作项：

```text
新增价格
上传报价
AI采集线索
创建询价
AI自动套价
生成报告
```

要求横向排列，不能做成大卡片堆叠。
