# 13 AI 占比提升升级方案

## 一、升级目标

原系统定位：

> 水厂项目机电设备与地材价格信息库

升级后定位：

> AI 驱动的水厂工程价格情报与套价决策系统

AI 从单一的“报价单识别工具”，升级为贯穿全流程的智能助手。

## 二、AI 占比提升后的核心变化

| 原版本 | 升级后 |
|---|---|
| AI 只识别报价单 | AI 覆盖采集、识别、清洗、匹配、比价、套价、风险、报告 |
| 人工主导录入 | AI 先整理，人工确认 |
| 表格系统为主 | AI 工作台 + 数据库并行 |
| 价格库被动查询 | AI 主动发现缺失、过期、异常价格 |
| 比价靠人工判断 | AI 给出推荐理由和风险项 |
| 套价靠人工匹配 | AI 自动匹配 BOQ 和价格库 |
| 证据链人工整理 | AI 自动归集附件和引用来源 |

## 三、AI 增强后的功能模块

### 1. AI 工作台

统一展示：

- 今日 AI 处理任务；
- 待人工复核；
- AI 识别成功率；
- 高风险 AI 结果；
- AI 推荐询价任务；
- AI 套价缺口；
- AI 生成报告。

### 2. AI 价格采集中心

用于创建价格采集任务：

- 设备价格采集；
- 厂家价格线索采集；
- 刚果金地材价格采集；
- 供应商联系方式采集；
- 市场价格趋势采集。

注意：采集结果只能进入“价格线索池”，不能直接进入正式价格库。

### 3. AI 报价识别中心

增强为：

- 报价单识别；
- 报价条件识别；
- 技术参数识别；
- 是否含税/运费判断；
- 漏项判断；
- 多语言报价单识别；
- 中英法设备名称转换；
- 风险提示。

### 4. AI 套价助手

增强为：

- BOQ 自动解析；
- 设备名称标准化；
- 规格相似度匹配；
- 价格库匹配；
- 无匹配项生成询价任务；
- 成本测算初稿；
- 推荐价格来源。

### 5. AI 比价分析助手

增强为：

- 多供应商横向对比；
- 价格异常判断；
- 技术偏差识别；
- 交货期风险判断；
- 报价条件不可比提醒；
- 推荐供应商；
- 商务谈判建议。

### 6. AI 风险预警中心

自动发现：

- 价格过期；
- 无附件证据；
- AI 结果未审核；
- 报价条件不完整；
- 材料价格波动过大；
- 供应商交付风险；
- 技术参数不一致；
- 低价异常。

### 7. AI 报告生成中心

自动生成：

- 设备价格分析报告；
- 地材价格月报；
- 供应商比价报告；
- 项目套价报告；
- 价格风险清单；
- 审计证据链摘要；
- 询价计划建议。

## 四、AI 与人工的边界

| 事项 | AI 可做 | 人工必须确认 |
|---|---|---|
| 识别报价单 | 是 | 是 |
| 推荐价格 | 是 | 是 |
| 判断风险 | 是 | 是 |
| 生成询价函 | 是 | 是 |
| 自动套价 | 是 | 是 |
| 供应商推荐 | 是 | 是 |
| 正式入库 | 否 | 是 |
| 投标采用价格 | 否 | 是 |
| 索赔证据采用 | 否 | 是 |

## 五、页面改造原则

每个核心页面增加 AI 辅助入口：

| 页面 | AI 增强 |
|---|---|
| 首页 | 增加 AI 工作台摘要 |
| 设备价格库 | AI 补全参数、AI 查找相似价格 |
| 地材价格库 | AI 整理市场调研记录、AI 价格波动提醒 |
| 供应商库 | AI 推荐供应商、AI 补全供应商信息 |
| 待审核报价池 | AI 风险评分、AI 缺失字段提醒 |
| 询价比价管理 | AI 生成询价函、AI 催收建议 |
| 比价详情 | AI 推荐供应商和谈判建议 |
| 项目套价中心 | AI 自动套价和无匹配项询价 |
| 附件库 | AI 自动归类和关联证据 |
| 统计分析 | AI 生成月报和异常解释 |
| 系统设置 | AI 参数、置信度和审核规则配置 |
