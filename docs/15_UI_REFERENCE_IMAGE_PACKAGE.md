## 三、开发使用方式

Codex 开发某个页面时，应同时读取：

1. `ui-prototype/` 对应页面规范；
2. `visual-references/09_UI_REFERENCE_IMAGE_INDEX_28P.md`；
3. `visual-references/ui-images/` 对应页面图片；
4. `data-spec/` 对应数据字段；
5. `codex-tasks/` 对应开发任务。

## 四、视觉验收标准

1. 左侧导航是否一致；
2. 顶部栏是否一致；
3. 主内容背景是否一致；
4. 卡片圆角、阴影、间距是否一致；
5. 表格风格是否一致；
6. 状态标签颜色是否一致；
7. AI 模块是否使用统一紫色/蓝色体系；
8. 风险提示是否使用橙红色；
9. 页面是否仍然保持水厂工程商务系统风格。

## 五、重要边界

这些图片只作为视觉参考，不能作为整页图片切入网页。
