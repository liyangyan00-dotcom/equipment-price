### 已发现的现有入口风险

- 项目套价详情中的 `/attachments/[id]` 入口已经由附件证据详情页承接，原死链风险已关闭。
- 其余当前页面跳转均指向现有静态路由或带 mock ID 的动态路由模板；`/comparisons` 在动作注册器中仅作为路由前缀，不是独立页面入口。

## 4. 不建议做独立路由（9）

| 功能 | 建议形态 | 原因 |
|---|---|---|
| 新增、编辑供应商 | Drawer / Modal | 依赖当前供应商列表或详情上下文 |
| 价格线索详情 | RightPanel / DetailDrawer | 需要与线索列表联动切换 |
| 待审核报价详情 | RightPanel | 需要与审核队列联动 |
| AI 推荐理由 | DetailDrawer / Panel | 属于解释信息，不需要单独地址 |
| 字段补全 | EditDrawer | 单条记录局部修正 |
| 附件快速预览 | PreviewPanel | 快速核验证据，不等同独立附件详情 |
| 导出设置 | ExportDialog | 短流程参数确认 |
| 驳回、作废、审核备注 | ConfirmDialog / Modal | 状态动作必须保留当前对象上下文 |
| 单行 BOQ 修正 | EditDrawer | 表格行级编辑，不应离开解析结果页 |

## 5. 重复页面判断

当前没有需要删除的重复页面。

- `/suppliers` 是供应商情报与评估页；`/suppliers/manage` 是资料维护和批量治理页。
- `/project-pricing` 是项目套价中心；`/project-pricing/boq-parse` 是 BOQ 解析结果页。
- `/ai-report-center` 是报告生成任务中心；`/reports` 是报告归档与版本治理页；`/reports/[id]` 是单份报告预览页。
- `/inquiries/[id]` 是询价任务档案；`/comparisons/[id]` 是比价决策页。

## 6. 执行边界

1. 当前无已批准但尚未开发的独立路由。
2. 新路由未经过页面总账评审前，不在侧边栏增加入口。
3. 新路由必须有明确业务对象、可刷新状态和独立访问价值。
4. 局部动作优先复用现有 Drawer、Modal、Panel 和 Dialog。
