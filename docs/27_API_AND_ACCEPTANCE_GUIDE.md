## 二、API 草案用途

API 草案用于后续真实后端或 Next.js Route Handlers 开发，当前阶段不实现。

覆盖模块：

- 登录、用户、权限；
- 设备价格；
- 地材价格；
- 供应商；
- AI 报价识别；
- 待审核报价；
- AI 价格采集；
- 价格线索池；
- 询价与比价；
- 项目套价；
- 附件证据；
- 报告生成；
- 统计分析；
- 系统设置。

## 三、页面验收表用途

页面验收表用于 Codex 后续完成页面后逐页检查：

- UI 是否还原；
- 字段是否完整；
- 资产是否用对；
- AI 流程是否正确；
- 表格和图表是否用代码实现；
- 是否违反 Image2/SVG/代码边界。
