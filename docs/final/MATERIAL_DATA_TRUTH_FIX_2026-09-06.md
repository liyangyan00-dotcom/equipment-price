# 地材价格页真实性修复

范围：`/material-prices`及共享地材记录映射。未修改云端数据或数据库结构。

## 已修复

- 移除预置准确率、线索数量、涨幅、地区水泥报价、缺口等级与“换一批”成功提示。
- 来源分布、地区记录数量、资料缺口和高风险数量由当前筛选的已加载记录计算。地区记录数量不再伪装成地区价格高低。
- 趋势基于当前选中材料的已审核价格，隔离规格、单位、原币、地区、来源、供应商、运输与含税条件。条件未知或不足两个报价日期时不生成涨跌判断；同日报价使用中位数。原币价不依赖推测汇率。
- 筛选项来自当前实际记录，不再从Mock字典读取；移除映射时的Mock记录补齐。
- 近30天更新按updatedAt动态计算，筛选与KPI使用同一函数，排除未来更新时间；不再写死2026年5月日期。
- 缺失报价日期保持未知，不再拿数据库updated_at充当报价日期；表头改为“报价日期”。缺失来源不再默认为人工录入。
- 线索摘要尚未取得/失败显示`--`，不显示成功取得的零条；价格加载失败不生成正常空样本分析。已加载记录量不声明为全库总量。
- AI线索KPI进入真实地材线索池；补充采集带地材对象和实际名称；趋势按钮选中记录并定位实际趋势模块。

## 验证

- `scripts/material-insights.test.mjs`：7项测试覆盖日期、动态窗口、真实筛选、统计总数、同口径隔离、中位数、风险与移除预置值。
- 与配置、权限、轮询、缓存及业务契约组合执行：104项通过。
- 修改文件ESLint通过、TypeScript通过。
- `scripts/material-insights-browser.cjs`：使用明确的合成样本渲染真实组件，1440/390宽度、填充/空状态均通过，无页面横向溢出；实际检查了截图。此为隔离组件验证，不是登录后的整页或真实数据验收。
- 截图位于本机忽略目录`artifacts/material-insights/`，不会作为真实业务成效证据。

## 日期与趋势回归补充（2026-09-06）

- 修复仅设置截止日期时，未知报价日期因空字符串比较而混入结果的问题。任一日期边界启用后，记录及边界必须是有效日历日期；起止边界包含当天，反向区间不匹配记录。无日期筛选时仍保留异常记录供人工修正。
- 日期单元格对无效日历日期显示“日期异常”，不交给格式化器滚动成其他日期，也不删除原记录。
- 历史趋势以北京时间当日为截止，未来报价不参与趋势；风险区单列未来日期数量，补充采集区提供复核入口。午夜边界已有固定时钟测试。
- 趋势横轴改为实际报价日期间距，不再按记录序号等距排布；展示真正参与趋势的样本条数。不同统计分母仍明确区分：来源/地区统计包括当前已加载记录，历史趋势仅包括满足可比条件的记录。
- 新增3项日期行为测试；组合回归107项通过。TypeScript、修改文件ESLint、生产构建通过。桌面1440与手机390隔离组件截图已检查，无页面横向溢出；浏览器测试验证1月1日、1月2日、2月1日的横轴比例，并确保未来报价不入曲线。
- 上述验证使用合成样本，不代表登录态整页、真实业务或公网评审验收；未修改云端数据库。

## 剩余事项

- 地材API仍需服务端分页、统计、筛选项及导出成套改造；当前分析明确只覆盖已加载样本，不宣称全量。
- 其他页面的预置值/历史Mock回退仍需逐项排查；本报告不代表全系统真实性已验收。
- Shared mapper不再制造报价日期会暴露历史缺失字段，需人工核验证据后补齐，不自动回填。
- 独立脱敏评审环境、登录态端到端、真实CDF闭环、云端安全迁移和Egress观察仍未关闭。
