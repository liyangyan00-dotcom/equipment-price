# 地材数据表达修复

日期：2026-09-06。属于R08本地补强，不代表全系统已通过发布验收。

## 核实的问题与处理

- 详情页原来把等级A/B/C/D/E反推为92/85/74/62/48%，并将其称为参数完整度。现改用数据库实际confidence分数，标签改为记录可信度。缺失或越界分数显示未评估，不反推百分比。
- 地材映射保留confidenceScore，评级允许null。真实0分保留，不与未知混同。主页、详情及管理页支持未评估显示；设备映射未在本轮扩大修改。
- 非USD报价缺少合法美元折算值时为null，导出为空，不补0。已记录0与未知区分；原币USD不进行汇率换算，采用原始金额。
- 缺少趋势结论不默认平稳；缺少AI意见不宣称已有正式业务判断。need_info由待审核状态与明确needsInformation标记共同确定，不覆盖终态。
- 主列表投影增加needsInformation，保留字段裁剪，不恢复完整metadata。
- 390px截图发现操作栏文字挤成竖排，给左侧计数与选择区固定不收缩、单行显示，继续使用局部横向滚动。
