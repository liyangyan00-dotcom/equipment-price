# 地材审核队列分页验收进度

日期：2026-09-06。状态：本地部分验证通过，R05及总体发布条件未关闭。

## 当前实现

- 审核队列使用独立 review-queue 接口，每页10条，服务端筛选及总数，不再由该组件一次加载全部地材记录。
- 显式裁剪价格字段与5个metadata键；不返回完整metadata及附件正文。
- 顶部组织统计使用5个HEAD精确计数，按组织、用户、角色缓存30秒；每次请求重新认证，失败不缓存。
- 高风险队列包含high与critical；待审核包含draft与pending_review；退回补充使用明确的needsInformation标记，不与字段完整度混淆。
- 翻页清除旧选择；单条/部分批量审核成功后刷新页与计数。失败保留服务器状态，不伪造成功。
- 导出按钮明确为“导出本页”，CSV包含原币币种并转义公式形式文本。
