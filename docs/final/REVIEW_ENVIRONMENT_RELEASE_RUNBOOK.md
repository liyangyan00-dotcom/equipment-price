# 独立脱敏评审环境发布手册

状态：准备中，尚未部署。本文是执行和验收要求，不是已通过的验收报告。

## 发布阻断

- 部署平台、公网域名、资源费用及资源创建授权未确认，不创建云端资源。
- 当前 `.env.example` 的 `NEXT_PUBLIC_SUPABASE_URL` 指向既有业务项目，不能直接复制为评审配置。必须确认评审项目与既有业务项目不同；仅新增组织不能替代独立数据库与存储隔离。
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` 必须属于评审项目。不得复用正式密钥、账号或会话；服务端高权限密钥不得放入任何 `NEXT_PUBLIC_` 变量。
- 前端公开环境变量必须在评审构建时注入。不得将绑定正式项目的已有构建产物直接部署到评审域名。
- 当前本地待确认安全迁移不等于线上权限已经生效；迁移执行、结构变化和样本导入需明确批准目标环境后进行。
- 附件权限本地复现发现编辑员可凭file.write最终确认、任务可分派给viewer，详见 `ATTACHMENT_REVIEW_PERMISSION_AUDIT_2026-09-06.md`；此项未修复，不得宣称全系统只读与审核隔离已经验收。
- 独立评审环境不支持通过删除配置进入Mock模式：生产缺少配置应返回503，不能绕过认证。

## 资源与身份登记

发布负责人填写以下字段，凭据仅存于部署平台的安全配置中，不写入本文或Git。

| 字段 | 发布前必须核实 |
| --- | --- |
| 发布版本 | 提交指纹、构建记录、门禁结果，禁止用脏工作树结果证明最终版本 |
| 评审地址 | 公网HTTPS域名及证书有效性，不是127.0.0.1或局域网地址 |
| 数据项目 | 独立项目标识、所属组织、费用方案，与正式项目不相同 |
| 存储 | 独立私有附件存储及访问策略，不能引用正式桶或正式签名链接 |
| 登录 | 评审域名的认证回调配置、只读viewer账号、有效成员关系 |
| 操作账号 | 与viewer分开，仅限授权演示人员，不提供给组委会 |
| 自动化 | 评审环境周期采集、外发邮件和外部调用初始不启动；正式环境保持原状 |
| 预算与退出 | 调用和流量上限、有效期、负责人、撤销访问与回滚流程 |

不把数据库角色、组织名称或页面“演示”标签当成隔离已经生效的证明。

## 样本导入准入

先形成逐文件清单，再由负责人批准导入。禁止整库复制和自动执行历史seed脚本。

每条样本登记：样本编号、授权依据、真实脱敏或合成类型、文件SHA-256、来源、价格所属期、币种、单位、规格、脱敏检查人、检查时间、业务引用关系。

检查范围包括附件正文、PDF隐藏文本与元数据、Excel隐藏工作表与批注、图片文字、签章、联系方式、邮件头、文件名及导出文件。仅替换供应商展示名称不合格。

重新生成组织、用户、供应商及业务记录标识，重新建立关联和附件路径；检查无正式组织标识、正式用户邮箱、内部域名及正式Storage链接残留。真实来源引用需保留可核验出处，合成样本明确标记“演示样本”，不得伪造授权或真实业务成效。

导入后核对每类记录数量、孤立引用、证据可访问性与价格字段。缺少日期、币种、单位、汇率依据的字段保留未知，不为了演示补造数值。

## 外部网络验收矩阵

每项记录版本、时间、账号角色、目标对象、预期与实际结果以及脱敏证据。当前所有项均待执行。

| 测试 | 通过要求 |
| --- | --- |
| 匿名访问 | 业务页要求登录；业务API拒绝访问，无缓存泄露 |
| viewer读 | 只读取评审组织允许的记录、附件和报告；刷新、深链正常 |
| viewer写 | 创建、编辑、删除、审核、运行Agent、触发采集均被服务端拒绝，数据库前后无变化 |
| 直接调用 | 绕过页面调用API、RPC、Storage和Edge仍不能越权；不能只检查按钮禁用 |
| 跨组织 | 用测试组织的对象标识、附件路径、导出条件和组织切换参数均不能读取或修改另一组织 |
| 权限覆盖 | viewer不存在组织级写入权限覆盖；停用成员或撤销会话后不得保留访问能力 |
| 原始文件 | 预览、下载、导出均为已审核脱敏内容，签名链接有有效期且无正式存储引用 |
| CDF闭环 | 授权操作账号完成证据到人工审核、价格落库、BOQ和报告引用核对；viewer仅查看结果 |
| 幂等 | 重复执行相同样本不重复正式落库，失败不会显示成功 |
| 网络与流量 | 外部设备访问成功；失败有限重试；隐藏页不持续轮询；记录实际请求与账单观测 |
| 小屏体验 | 桌面与手机无不可操作控件、遮挡和页面溢出 |

独立测试组织使用合成数据，越权测试不以正式业务对象作为可写目标。

## 发布与回滚

1. 在确认的平台创建隔离资源后，重新核实项目标识、环境变量和目标迁移计划；禁止默认使用现有CLI链接目标。
2. 对最终冻结版本执行Lint、构建、累计测试、迁移核对及浏览器回归。离线迁移核对通过不代表迁移已执行。
3. 经授权配置评审数据库和存储，导入批准样本，创建仅属于评审组织的账号；记录操作及结果。
4. 完成上表外部网络验收，检查访问日志不包含密码、Token或敏感附件内容，再发送地址和单独传递的账号信息。
5. 任一隔离、脱敏或写权限测试失败即停止交付。先撤销评审账号和评审环境任务权限，必要时下线评审部署；不关闭正式功能、不删除正式数据。
6. 回滚到上一已验收构建时，同时检查数据库兼容性；不得自动执行破坏性逆向迁移或删除样本。保留脱敏事件记录，修复后重跑失败项及相关权限回归。

最终交付包：公网地址、使用有效期、账号获取方式、版本指纹、脱敏样本清单、验收记录、已知限制、演示录像和恢复联系人。未验收项不得标记完成。
