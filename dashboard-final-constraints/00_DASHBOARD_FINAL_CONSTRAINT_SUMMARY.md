# 00 首页最终约束总说明

本目录用于沉淀 `/dashboard` 首页最终约束，作为全系统视觉风格和页面质感的基准。

核心原则：

```text
首页是视觉基准，不是所有页面的布局模板。
其他页面继承首页风格，但不得照搬首页驾驶舱布局。
```

首页最终定位：

```text
AI价格情报工作台 / 运营驾驶舱 / 全系统入口
```

首页最终结构：

```text
01 顶部轻量工作台 Hero
02 6张紧凑 KPI 卡
03 主驾驶舱：价格趋势分析 + AI工作台
04 运营流：最新价格动态 + 待复核任务
05 AI洞察三联卡
06 快捷操作栏
07 辅助分析：分布图
08 风险决策：风险预警 + AI建议动作
```

可迁移到所有页面：
1. 色彩体系；
2. 字体体系；
3. 圆角卡片；
4. 图标容器；
5. 模块标题区；
6. AI紫色识别；
7. 风险橙红识别；
8. compact 表格；
9. 截图对比机制。

不可照搬到所有页面：
1. 首页的 6 KPI 布局；
2. 首页的 Row 结构；
3. 首页的趋势图 + AI工作台主结构；
4. 首页的三联卡数量；
5. 首页的驾驶舱高密度结构。
