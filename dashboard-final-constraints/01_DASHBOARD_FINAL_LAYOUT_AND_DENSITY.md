# 01 首页最终布局与密度约束

首屏目标：

```text
Hero
KPI
价格趋势 + AI工作台
价格动态 / 待复核任务的大部分
AI洞察卡顶部
```

不强制所有模块完整进入首屏，但必须减少长页感。

最终尺寸建议：

| 区域 | 建议高度 |
|---|---|
| Topbar | 52px - 56px |
| Hero | 58px - 72px |
| KPI 卡 | 88px - 104px |
| 主趋势图 | 250px - 270px |
| AI工作台 | 与主趋势图等高 |
| 价格动态行 | 38px - 44px |
| 待复核任务行 | 38px - 44px |
| AI洞察卡 | 104px - 132px |
| 分布图 | 160px - 200px |
| 快捷操作栏 | 64px - 72px |

间距约束：

| 项 | 建议 |
|---|---|
| 页面左右 padding | 16px - 20px |
| 模块纵向 gap | 10px - 14px |
| 卡片内部 padding | 12px - 16px |
| 卡片圆角 | 14px - 16px |
| 卡片阴影 | 轻阴影，不可过重 |

不得出现：
1. 仍像普通后台；
2. 模块像卡片堆叠；
3. 右侧 AI 工作台过弱；
4. 表格像 Excel；
5. 分布图过大；
6. 快捷栏过弱；
7. 风险和 AI 建议割裂；
8. 首屏只看到少量模块。
