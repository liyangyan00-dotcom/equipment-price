# 02 首页最终视觉约束

Hero 必须是工作台状态区，不是普通说明横幅。

Hero 必须包含：
1. 页面标题；
2. 简短说明；
3. 今日 AI 任务；
4. 待复核数量；
5. 更新时间；
6. 进入 AI 工作台按钮。

KPI 卡结构：

```text
上：标题 + 图标容器
中：核心数字
下：趋势 Badge + 简短说明
```

KPI 色彩：
| KPI | 颜色 |
|---|---|
| 设备价格 | 蓝 |
| 地材价格 | 青 |
| 供应商 | 蓝绿 |
| AI待复核 | 紫 |
| 今日线索 | 紫 |
| 高风险 | 橙红 |

AI工作台必须像“智能中枢”，不是普通卡片。

AI工作台结构：

```text
Header：AI图标 + 标题 + 智能中枢Badge + 查看入口
Body 1：4个紧凑指标块
Body 2：AI处理进度
Body 3：AI最新建议 + 推荐动作
```

价格动态必须像“价格情报流”，待复核任务必须像“任务处理队列”。

风险和 AI建议必须形成闭环：

```text
价格已过期 → 重新询价
低价异常 → 补充报价来源
参数缺失 → 补充资料
可信度低 → 人工复核
```

图标体系：
1. 优先 lucide-react；
2. 图标必须放进统一 IconBox；
3. 不使用 PNG 图标；
4. AI 用紫色；
5. 风险用橙红；
6. 普通数据用蓝/青。
