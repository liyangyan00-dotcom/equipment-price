# 00 Dashboard 参考图拆解总说明

## 一、目的

本规范用于把 `/dashboard` 从“已具备功能的首页”提升到“高度接近参考图的高密度运营驾驶舱”。

参考基准：

```text
visual-references/ui-images/01_dashboard_ai_price_intelligence.png
```

## 二、当前问题总结

当前 Dashboard 常见问题：

1. 模块虽然齐全，但像“平铺堆叠”；
2. 主次关系不清，缺少驾驶舱逻辑；
3. 统计卡过高，首屏被拉散；
4. 趋势图、AI工作台、列表区比例不合理；
5. 信息密度偏低，像普通后台；
6. 图标、标题、卡片视觉语言不统一；
7. AI模块识别度弱；
8. 风险模块不够像运营问题面板；
9. 快捷入口像普通卡片，不像工具操作栏；
10. 没有严格按参考图做逐区块复刻。

## 三、参考图的真实结构理解

参考图并不是简单“很多模块”，而是一个有强节奏的首页：

```text
顶部概览
→ 主趋势 + AI工作台
→ 运营流（价格动态 / 待复核）
→ AI洞察
→ 分布分析
→ 风险运营
→ 操作闭环
```

## 四、本轮原则

1. 只修 `/dashboard`；
2. 不开发其他业务页面；
3. 不进入 Round 5；
4. 不接真实数据库或 AI API；
5. 不使用整页切图；
6. 图表、表格、卡片、按钮、状态标签全部代码实现；
7. 图标体系优先使用 `lucide-react`；
8. 只有当 `lucide-react` 不能满足一致性时，才考虑补一套 `assets/svg-icons/dashboard/`。

## 五、如何使用本规范

执行顺序：

1. 阅读本目录全部文件；
2. 先按红线布局重排 Dashboard；
3. 再按视觉规则调色、调字号、调图标容器；
4. 再按差异清单逐项修复；
5. 最后做截图对比修正。
