# 01 Dashboard 红线布局规范

## 一、页面总结构

固定结构如下：

```text
PageHeader
Row 1：6张压缩统计卡
Row 2：左8列价格趋势图 / 右4列AI工作台总览
Row 3：左7列最新价格动态 / 右5列待复核任务
Row 4：3张AI价格情报洞察卡
Row 5：3个分布图模块
Row 6：风险预警列表
Row 7：横向快捷操作栏
```

不允许随意打乱顺序。

## 二、栅格规则

### 顶层内容区
- 使用 12 栅格；
- 模块 gap：12px - 16px；
- 卡片间纵向间距：12px - 16px。

### Row 1 统计卡
- `grid-cols-6`；
- 桌面端优先一行 6 张；
- 高度必须压缩。

### Row 2 主驾驶舱
- 左 8 列：价格趋势图；
- 右 4 列：AI 工作台总览；
- 两块高度尽量接近。

### Row 3 运营流
- 左 7 列：最新价格动态；
- 右 5 列：待复核任务；
- 强调“动态流 + 任务流”的并列关系。

### Row 4 AI 洞察
- 3 张横向卡片；
- 同高；
- 每张卡片内容密度高于普通说明卡。

### Row 5 分布图
- 3 张小图表卡片；
- 同高；
- 不抢主图。

### Row 6 风险预警
- 建议占满 12 列；
- 列表式，强调运营问题。

### Row 7 快捷操作栏
- 6 个横向操作入口；
- 不做大卡片墙；
- 优先一排展示。

## 三、禁止事项

1. 不要把趋势图做成超高大卡；
2. 不要把 AI 工作台缩成很弱的小块；
3. 不要让分布图出现在趋势图上方；
4. 不要让快捷入口跑到中上部；
5. 不要把风险模块做成一句提示；
6. 不要因为响应式而牺牲桌面端主布局。
