# 15 Dashboard 截图差异闭环流程

## 一、目的

高度还原参考图，不能只靠文字自查，必须做截图对比。

## 二、推荐流程

```text
1. npm run dev
2. 打开 /dashboard
3. 生成当前页面截图
4. 与 visual-references/ui-images/01_dashboard_ai_price_intelligence.png 对比
5. 输出差异表
6. 根据差异表二次修复
7. 再截图
8. 再对比
```

## 三、差异表格式

Codex 输出必须包含：

| 区域 | 参考图特征 | 当前页面问题 | 修复动作 | 是否完成 |
|---|---|---|---|---|
| 顶部统计卡 | 6张紧凑横排 | 当前过高 | 降低高度和padding | 是/否 |
| 主图区 | 左趋势右AI | 比例不对 | 调整grid | 是/否 |

## 四、必须对比的区域

1. 顶部统计卡；
2. 趋势图；
3. AI工作台；
4. 最新价格动态；
5. 待复核任务；
6. AI洞察三联卡；
7. 分布图；
8. 风险列表；
9. 快捷操作栏；
10. 标题图标系统；
11. 页面整体密度；
12. 颜色和字体气质。

## 五、必须输出结论

每次截图对比后必须输出：

```text
已接近参考图的部分
仍然明显不像的部分
下一步修复清单
是否可以进入 Round 5
```

## 六、不可跳过

没有截图对比，不得进入 Round 5。
