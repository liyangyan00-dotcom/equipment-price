# 05 Dashboard 图标与标题系统规范

## 一、总原则

Dashboard 的“高级感”不依赖大图片，而依赖：

1. 统一图标风格；
2. 统一图标容器；
3. 统一标题层级；
4. 统一小标签系统。

## 二、图标优先策略

### 第一优先：lucide-react

优先使用 `lucide-react`，原因：
- 风格统一；
- 线性图标干净；
- 易于代码控制；
- 不需要额外生成图片。

### 第二优先：项目现有 SVG

仅当 `lucide-react` 无法满足特定模块一致性时，可补充：

```text
assets/svg-icons/dashboard/
```

但本轮不是必须，不得先生成 PNG 图标替代。

## 三、推荐图标映射

| 模块 | 推荐图标 |
|---|---|
| 首页概览 | `LayoutDashboard` |
| AI工作台 | `Bot` / `Sparkles` |
| 价格趋势 | `TrendingUp` |
| 最新价格动态 | `Activity` |
| 待复核任务 | `ClipboardCheck` / `FileSearch` |
| AI洞察 | `BrainCircuit` / `Sparkles` |
| 设备分类分布 | `PieChart` |
| 供应商区域分布 | `MapPin` |
| 可信度分布 | `BarChart3` |
| 风险预警 | `AlertTriangle` |
| 快捷操作栏 | `Zap` |
| 生成报告 | `FileText` |

## 四、图标容器规范

模块标题图标不要裸露使用，必须放入图标容器：

- 尺寸：32px 或 36px
- 圆角：10px 或 12px
- 图标尺寸：16px - 18px
- 对齐：居中

## 五、图标颜色规则

### 普通数据模块
- 容器背景：浅蓝 `#E8F2FF`
- 图标颜色：工程蓝 `#0B5CAD`

### AI 模块
- 容器背景：浅紫 `#F5F3FF`
- 图标颜色：AI紫 `#7C3AED`

### 风险模块
- 容器背景：浅橙 `#FEF3C7`
- 图标颜色：预警橙 `#F59E0B`

### 成功 / 确认模块
- 容器背景：浅绿 `#ECFDF3`
- 图标颜色：成功绿 `#16A34A`

## 六、标题区规范

每个模块标题区建议结构：

```text
[图标容器] [标题] [可选小标签]
            [副标题/说明]
```

规则：
- 标题：14px - 16px / 600
- 副标题：11px - 12px / 400
- 小标签：微型 badge，不要太大

## 七、禁止事项

1. 不要随意混用多套图标风格；
2. 不要直接塞 PNG 图标；
3. 不要每个模块一个完全不同的图标背景风格；
4. 不要让标题图标比文字还抢眼；
5. 不要使用过于卡通的 AI 图标。
