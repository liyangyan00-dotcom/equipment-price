# 04 Dashboard 视觉调优规范

## 一、整体气质

目标风格：

```text
工程蓝 + AI紫 + 风险橙红
专业 / 稳定 / 高级 / 紧凑 / 科技感
```

## 二、色调建议

### 页面与卡片
- 页面背景：`#F3F7FB`
- 卡片背景：`#FFFFFF`
- 浅区块背景：`#F8FAFC`
- 边框：`#E2E8F0`

### 主色
- 工程蓝：`#0B5CAD`
- 深蓝：`#061B3A`
- 深蓝辅助：`#0B2454`
- 青蓝高亮：`#00A6B8`

### AI色
- AI紫：`#7C3AED`
- AI辅助紫：`#8B5CF6`
- AI浅背景：`#F5F3FF`
- AI浅边框：`#DDD6FE`

### 状态色
- 成功绿：`#16A34A`
- 预警橙：`#F59E0B`
- 风险红：`#DC2626`

## 三、字体层级

- 页面标题：24px / 600
- 区块标题：16px / 600
- 卡片标题：14px / 600
- 正文：13px / 400
- 表格正文：12px - 13px / 400
- 辅助说明：11px - 12px / 400
- 大数字：24px - 28px / 700

颜色：
- 主标题：`#1E293B`
- 次标题：`#334155`
- 正文：`#475569`
- 辅助：`#64748B`

## 四、卡片视觉

- 圆角：16px
- 常规阴影：`0 8px 24px rgba(15,23,42,0.06)`
- 悬浮/重点卡片可略增强，但不要过度
- 内边距：16px - 20px

## 五、图表视觉

- 不使用默认鲜艳随机色；
- 图例、Tooltip、网格线要统一；
- 网格线淡化；
- 主趋势线颜色固定；
- Tooltip 使用白底圆角轻阴影。

## 六、AI模块视觉

- 使用浅紫底 + 紫色强调；
- 必须有 AiBadge；
- 建议动作区使用浅色强调块；
- 不使用大插画。

## 七、风险模块视觉

- 列表式问题面板；
- 高风险红，中风险橙，低风险绿；
- 建议动作可用轻按钮或文字操作链接。
