# 11 Dashboard 模块内部结构细化规范

## 一、目的

V4.8 已经规定了 Dashboard 的行结构和模块位置，但要高度还原参考图，还必须约束每个模块内部如何排版。

本文件用于防止 Codex 只把模块“放对位置”，但模块内部仍然像普通后台。

## 二、统一模块标题区结构

所有 Dashboard 模块标题区建议采用：

```text
左侧：[图标容器] + [标题 + 副标题]
右侧：[筛选 / AI标签 / 查看全部 / 操作按钮]
```

规则：

| 项 | 规范 |
|---|---|
| 标题区高度 | 40px - 48px |
| 图标容器 | 32px / 36px |
| 标题字号 | 14px - 16px / 600 |
| 副标题字号 | 11px - 12px / 400 |
| 右侧操作 | 12px - 13px，轻量按钮或标签 |

## 三、StatCard 内部结构

结构：

```text
Top：标题 + 图标容器
Middle：核心数字 + 单位
Bottom：趋势说明 / 更新时间
```

尺寸：

```text
高度：96px - 108px
padding：14px - 16px
数字：24px - 28px / 700
图标容器：32px
```

禁止：

1. 不要把统计卡做成大海报；
2. 不要放过多说明；
3. 不要单张卡片高度超过 120px。

## 四、价格趋势图内部结构

结构：

```text
Header：图标 + 标题 + 副标题 + 右侧时间筛选
Chart：LineChart
Footer：可选图例 / 数据说明
```

规则：

1. 时间筛选在右上角；
2. 图例简洁；
3. Tooltip 必须白底圆角；
4. 图表区不能挤压标题区；
5. 图表线条使用工程蓝、青蓝、AI紫。

## 五、AI 工作台总览内部结构

结构：

```text
Header：AI图标 + 标题 + AiBadge
Body Top：今日任务 / 成功率
Body Middle：风险结果 / 建议动作 / 待复核
Body Bottom：最近AI建议
```

建议：

```text
信息块采用 2列网格
成功率使用 AiConfidenceBar
最近建议使用浅紫色提示块
```

禁止：

1. 不要放大插图；
2. 不要只显示一句 AI 文案；
3. 不要没有置信度或成功率。

## 六、最新价格动态行结构

每一行建议：

```text
左侧：类型Badge + 名称
中部：来源 + 更新时间
右侧：价格 + ConfidenceBadge + AiBadge
```

行高：

```text
44px - 52px
```

金额必须右对齐。

## 七、待复核任务行结构

每一行建议：

```text
左侧：文件类型图标 + 文件名
中部：任务类型 + 缺失字段
右侧：置信度 + 风险等级 + 操作入口
```

操作入口：

```text
查看 / 复核 / 补充资料
```

缺失字段用黄色，风险等级用 RiskBadge。

## 八、AI 洞察三联卡内部结构

每张卡：

```text
Header：AI图标 + 标题
Metric：核心指标
Description：一句说明
Action：建议动作
```

高度：

```text
132px - 152px
```

## 九、分布图卡片内部结构

结构：

```text
Header：图标 + 标题 + 简短说明
Chart：小图表
Footer：图例或关键数据
```

要求：

1. 不要超过主趋势图视觉权重；
2. 图例简短；
3. 图表高度统一。

## 十、风险预警列表内部结构

每条风险：

```text
左侧：风险色条 / 风险图标
中部：风险标题 + 影响对象 + 建议动作
右侧：RiskBadge + 操作入口
```

高风险必须明显，但不要大红块泛滥。

## 十一、横向快捷操作栏内部结构

每个操作项：

```text
左侧：图标容器
右侧：标题 + 一句说明
```

AI类操作使用紫色图标容器，普通操作使用蓝色图标容器，风险/审核类可用橙色。

高度：

```text
72px - 84px
```
