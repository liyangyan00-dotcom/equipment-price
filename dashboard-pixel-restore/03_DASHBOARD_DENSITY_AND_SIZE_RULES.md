# 03 Dashboard 信息密度与尺寸规则

## 一、全页密度目标

首页不是营销页，而是高密度运营驾驶舱。

必须达到：
- 首屏看到统计卡 + 2个核心模块；
- 模块连续分布，不松散；
- 信息阅读顺序清楚；
- 页面整体紧凑但不拥挤。

## 二、尺寸红线

### 统计卡
- 高度：96px - 108px
- 内边距：16px
- 数字字号：24px - 28px
- 标题字号：13px - 14px
- 趋势说明：11px - 12px
- 图标容器：32px - 36px

### 主图表卡
- 卡片高度：260px - 280px
- 图表区域高度：200px - 220px
- 标题区高度尽量紧凑

### AI工作台
- 卡片高度尽量接近主图表
- 内部分块采用 2列或紧凑网格
- 进度条和小统计块为主

### 列表 / 小表格
- 行高：44px - 52px
- 表头紧凑
- 金额右对齐
- 标签小型化

### AI洞察卡
- 高度：132px - 152px
- 不可留白过大

### 分布图卡
- 高度：220px - 240px
- 图表区域高度：140px - 160px

### 风险列表
- 单条高度：56px - 72px
- 5条左右为宜

### 快捷操作栏
- 单项高度：72px - 84px
- 图标容器：32px
- 标题：13px - 14px
- 说明：11px - 12px

## 三、间距规则

- 页面区块之间：16px - 20px
- 卡片之间：12px - 16px
- 卡片内部标题与内容：10px - 14px
- 同组信息块之间：8px - 12px

## 四、密度禁止事项

1. 不要出现超高空白卡片；
2. 不要把图表做成海报式大图；
3. 不要把列表行高做得过松；
4. 不要让卡片 padding 过大；
5. 不要为了密度牺牲层级与可读性。
