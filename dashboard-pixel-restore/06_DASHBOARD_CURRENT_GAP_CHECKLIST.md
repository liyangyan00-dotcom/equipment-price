# 06 Dashboard 当前版本差异清单

以下是当前页面相对参考图最常见的差异，Codex 必须逐项修复：

1. 顶部统计卡过高，导致首屏过松；
2. 趋势图面积不合理，主次关系不稳；
3. AI工作台过弱，不像小型指挥台；
4. 最新价格动态不够像运营流；
5. 待复核任务缺少强操作感；
6. AI洞察卡过普通，像普通说明卡；
7. 分布图与主模块的层级关系不清；
8. 风险预警不够像问题运营面板；
9. 快捷入口像散落卡片，不像工具栏；
10. 整体信息密度低于参考图；
11. 图标系统太普通，没有统一图标容器；
12. 标题层级弱，文字气质普通；
13. AI 模块紫色识别不够；
14. 风险色使用不够明确；
15. 列表和表格的行高偏松；
16. 部分卡片 padding 过大；
17. 页面整体阅读顺序不够清楚；
18. 模块之间像并列堆叠，缺少驾驶舱节奏。

## 修复方式

每一项必须落实到：
- 布局调整；
- 组件尺寸调整；
- mock 数据结构补充；
- 视觉 token 使用；
- 图标容器和标题体系补全。
