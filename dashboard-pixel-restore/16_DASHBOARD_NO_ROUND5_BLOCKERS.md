# 16 不得进入 Round 5 的硬性阻断条件

## 一、出现以下任一情况，不得进入 Round 5

1. 首页仍像普通后台；
2. 模块仍然只是平铺堆叠；
3. 顶部统计卡仍然过高；
4. 趋势图与 AI 工作台主次不清；
5. 最新价格动态不像运营流；
6. 待复核任务不像任务流；
7. AI洞察三联卡像普通说明卡；
8. 分布图层级过强或过弱；
9. 风险预警不是列表式问题面板；
10. 快捷入口不是横向工具栏；
11. 标题图标仍然裸露或普通；
12. AI模块紫色识别不明显；
13. 风险模块橙红识别不明显；
14. 图表仍有默认 Recharts 味；
15. 列表行高太松；
16. 卡片 padding 太大；
17. 页面存在大面积空白；
18. 未完成截图对比；
19. 未通过 `dashboard-pixel-restore/09_ROUND_4_2_SCREENSHOT_COMPARE_CHECKLIST.md`；
20. 未通过 `dashboard-enhancement/05_DASHBOARD_ACCEPTANCE_CHECKLIST.md`。

## 二、进入 Round 5 的最低条件

必须同时满足：

1. Dashboard 布局符合红线；
2. 信息密度明显接近参考图；
3. 模块顺序与参考图逻辑一致；
4. 图标与标题系统统一；
5. 截图对比后无重大差异；
6. npm run dev 正常；
7. npm run build 正常；
8. 没有开发其他业务页面。
