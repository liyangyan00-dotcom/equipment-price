# 00 页面验收表总说明

## 一、用途

本目录用于后续 Codex 完成页面后逐页验收，确保：

- UI 尽可能还原 28 页参考图；
- 业务字段不遗漏；
- Image2 / SVG / 代码边界正确；
- mock 数据真实；
- AI流程合理；
- 页面可继续接数据库和 API。

## 二、验收分级

| 等级 | 含义 |
|---|---|
| P0 | 必须通过，否则页面不合格 |
| P1 | 应尽量通过，可小幅调整 |
| P2 | 优化项，可后续完善 |

## 三、通用验收项

每个页面都必须检查：

1. 是否使用统一侧边栏；
2. 是否使用统一顶部栏；
3. 是否继承首页深蓝 + 白卡片风格；
4. 是否使用字段字典字段；
5. 是否使用 mock 数据；
6. 是否没有整页切图；
7. 是否没有用 Image2 承载业务表格；
8. 是否使用 SVG / lucide-react 图标；
9. 是否有合适空状态；
10. 是否可响应式适配桌面端。
