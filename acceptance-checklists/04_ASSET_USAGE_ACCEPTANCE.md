# 04 资产使用验收表

| 资产类型 | 验收项 | 等级 | 通过标准 |
|---|---|---|---|
| UI参考图 | 是否整页切图 | P0 | 不允许整页切图 |
| Image2背景 | 登录页背景 | P0 | 使用 `login_water_plant_ai_bg.png` |
| Image2侧栏图 | 侧栏底部图 | P1 | 使用 `sidebar_water_plant_thumb.png` |
| Image2报告封面 | 报告封面 | P1 | 使用 `report_cover_water_plant.png` |
| 空状态插图 | 空状态 | P1 | 使用对应 empty_*.png |
| AI功能插图 | AI模块装饰 | P2 | 使用 ai_*.png |
| SVG Logo | Logo | P0 | 使用 `logo_water_price_system.svg` 或等效组件 |
| SVG图标 | 菜单/操作/状态 | P1 | 使用 svg-icons 或 lucide-react |
| 图表 | 趋势/分布/雷达 | P0 | 使用代码图表，不用图片 |
| 表格 | 业务表格 | P0 | 使用代码实现，不用图片 |
