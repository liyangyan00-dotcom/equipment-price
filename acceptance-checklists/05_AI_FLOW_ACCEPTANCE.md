# 05 AI流程验收表

| AI流程 | 验收项 | 等级 | 通过标准 |
|---|---|---|---|
| 报价识别 | 上传文件 | P0 | 有上传区和文件类型提示 |
| 报价识别 | 识别结果 | P0 | 显示供应商、日期、币种、明细 |
| 报价识别 | 风险提示 | P0 | 显示缺失税费、运费、质保等风险 |
| 待审核 | 人工复核 | P0 | 有确认、需补充、作废操作 |
| 价格采集 | 线索池 | P0 | AI采集结果进入线索池，不直接入库 |
| 比价分析 | 推荐供应商 | P1 | 有推荐理由和风险说明 |
| 项目套价 | 匹配等级 | P0 | 精准/相似/类别/无匹配 |
| 报告生成 | 人工编辑 | P1 | AI报告生成后可人工编辑 |
| 证据链 | 附件关联 | P0 | AI结果保留来源文件或附件 |
